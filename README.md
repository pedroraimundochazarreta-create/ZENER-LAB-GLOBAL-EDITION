# ZENER LAB GLOBAL EDITION - Statistical Research Suite

## Descripción Técnica
Este repositorio documenta el marco metodológico y estadístico utilizado en **ZENER LAB**, una herramienta avanzada diseñada para la automatización de protocolos de investigación en parapsicología experimental y percepción extrasensorial (ESP).

## Características del Sistema
* **Registro de Datos:** Automatización de pruebas con cartas Zener eliminando el sesgo del experimentador.
* **Análisis Estadístico:** Cálculo en tiempo real de desviaciones estándar y significancia (p-value).
* **Base de Datos:** Estructura preparada para el almacenamiento acumulativo de ensayos (Próximamente: Telepatía entre terminales).

## Objetivo de la Investigación
Estandarizar la recolección de datos en laboratorios independientes para permitir el análisis de metadatos a escala global.
